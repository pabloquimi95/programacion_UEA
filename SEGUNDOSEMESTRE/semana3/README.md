# Comparación entre Programación Tradicional y Programación Orientada a Objetos

## Autor

Pablo Sergio Quimi Pin

## Descripción

Este repositorio contiene dos soluciones para un mismo problema utilizando diferentes paradigmas de programación:

- Programación Tradicional.
- Programación Orientada a Objetos.

Ambos programas permiten gestionar información básica de mascotas, registrando y mostrando sus datos correspondientes.

## Reflexión

El desarrollo de esta práctica me permitió analizar cómo cambia la estructura lógica al resolver un mismo problema bajo dos perspectivas diferentes. En la Programación Tradicional, el flujo es puramente secuencial; el código se organiza en funciones que dependen de datos externos que viajan de forma aislada a lo largo del programa.

En contraste, la Programación Orientada a Objetos propone un diseño más intuitivo y ordenado. Al integrar los datos de la mascota (atributos) con sus comportamientos (métodos) dentro de una misma clase, logramos unificar la información en una sola entidad coherente.

Como conclusión del ejercicio, considero que la POO no solo aporta limpieza y modularidad al repositorio, sino que simplifica la representación de elementos del mundo real en el software. Esto se traduce en un código significativamente más fácil de mantener, escalar y adaptar a futuros requerimientos.
