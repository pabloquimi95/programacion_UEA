## 📝 Descripción del Proyecto

Este repositorio contiene la resolución de un sistema básico de gestión de mascotas desarrollado bajo dos enfoques de programación diferentes utilizando **Python 3**. El objetivo es evaluar y comparar cómo estructuralmente cambia el código, el manejo de la información y la modularidad entre la programación estructurada y la orientada a objetos.

El sistema administra la información básica de una mascota recopilando los siguientes datos mínimos:
* Nombre
* Especie
* Edad
